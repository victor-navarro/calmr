# CalmrDesign methods

S4 methods for `CalmrDesign` class.

## Usage

``` r
# S4 method for class 'CalmrDesign'
show(object)

# S4 method for class 'CalmrDesign'
mapping(object)

# S4 method for class 'CalmrDesign'
trials(object)
```

## Arguments

- object:

  A `CalmrDesign` object

## Value

`show()` returns NULL (invisibly).

`mapping()` returns a list with trial mappings.

[`trials()`](https://victornavarro.org/calmr/reference/CalmrExperiment-methods.md)
returns NULL (invisibly).
